# Experimento do plano inclinado

Protocolo didático seguro, inspirado em Galileu e na reconstrução de Straulino (2008). Os arquivos desta pasta não contêm medições históricas.

## Arquivos

- `protocolo.md`: procedimento completo.
- `ficha-de-dados.csv`: cabeçalho vazio para o leitor.
- `dados-simulados.csv`: **DADOS SIMULADOS**, semente editorial `20260820`.
- `analise.py`: análise sem dependências externas; gera resumo, ajustes e SVG.

## Executar

```powershell
python analise.py
```

Saídas: `resultado-analise.json`, `resumo-por-posicao.csv`, `residuos.csv` e `grafico-plano-inclinado.svg`.

## Segurança

Use supervisão adulta, rampa baixa e fixada, esfera leve, retenção acolchoada e celular em tripé. Não use bordas altas, vidro, trânsito de pessoas, eletricidade exposta nem olhe para o Sol em qualquer extensão óptica.
